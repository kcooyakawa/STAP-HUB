# Stap · Hub de marca

Site estático (GitHub Pages) com os materiais da identidade 2026.

- `index.html` — hub
- `templates.html` — prévia do template de apresentação + downloads (.pptx, fontes, logos)
- `assinatura.html` — gerador de assinatura de e-mail
- `assets/` — slides de prévia, template, fontes, logos

Publicar: Settings › Pages › Deploy from branch › main / root.
Para atualizar o template, substitua `assets/templates/Stap_Template_Apresentacao_2026.pptx` e as imagens em `assets/slides/`.
